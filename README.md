# SmartGen

## Project Overview
SmartGen is a web application that allows users to convert text into audio format and generate simplified PowerPoint presentations. This tool is designed to enhance accessibility and streamline the process of creating presentation materials from textual content.

## Features
- Text-to-Audio Conversion: Seamlessly convert text into audio files using advanced speech synthesis technology.
- PowerPoint Generation: Create simplified PowerPoint documents from the provided text, making it easier to prepare presentations.

## Setup Instructions
To set up and run the SmartGen web app locally, follow the steps below:

### Prerequisites
- Node.js (version 14 or above)
- npm (Node Package Manager)
- A modern web browser

### Installation Steps
1. **Clone the repository:**
   ```bash
   git clone https://github.com/owendo/SmartGen.git
   ```

2. **Navigate to the project directory:**
   ```bash
   cd SmartGen
   ```

3. **Install dependencies:**
   ```bash
   npm install
   ```

4. **Start the development server:**
   ```bash
   npm start
   ```

5. **Open your web browser and access the app at:**  
   `http://localhost:3000`

### Usage
- To convert text to audio, input the desired text in the provided input field and click the "Convert" button. 
- To generate a PowerPoint presentation, enter the relevant text and click the "Generate PPT" button.
